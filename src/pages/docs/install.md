# Установка

## Windows 10/11

Есть два файла на выбор — оба в [релизах](/releases):

- **портативная сборка** (`.exe`): один файл, ничего не пишет в систему, обновляется сам;
- **установщик** (nsis): ставится в папку, обновляется установщиком поверх.

Первый запуск Windows может предупредить, что издатель неизвестен: подписи кода у проекта пока
нет. Файлы подписаны minisign-ключом, который приложение проверяет перед обновлением.

## Android

Скачайте `.apk` и установите. Приложение попросит разрешение на установку из этого источника —
оно нужно системе, чтобы применить обновление. Данные при обновлении сохраняются.

## Linux

Бинарник принадлежит пакетному менеджеру, поэтому приложение не подменяет его само: в настройках
показывается новая версия и ссылка на страницу релиза. Обновление ставится вашим пакетным
менеджером.

## Обновления

Приложение проверяет манифест релиза и обновляется само: скачивает файл своей платформы, проверяет
sha256 и подпись, и только потом применяет. Порядок на всякий случай:

1. Windows, портативная папка — подменяет `.exe` рядом с собой и перезапускается.
2. Windows, установка в `Program Files` — скачивает установщик и запускает его.
3. Android — кладёт apk в кеш и отдаёт системному установщику.

Откатиться на старую версию нельзя: клиент принимает только версию выше. Исправление выпускается
новой сборкой.

## Где живут данные

Хранилище — папка, которую вы выбрали. Вложения — в `.attachments/`, удалённое — в `.trash/`.
Настройки и ключи — в локальном хранилище приложения, вне папки с заметками.
