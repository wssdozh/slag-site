# Синхронизация

## Что происходит

Устройства обмениваются пакетами изменений. Пакет шифруется на устройстве-отправителе, сервер
передаёт его и удаляет сразу после подтверждения доставки. История изменений на сервере не хранится.

Ключ хранилища не покидает ваши устройства: сервер видит идентификатор комнаты, размер пакета и
время, но не содержимое.

## Сопряжение устройств

1. На первом устройстве: «Настройки → Синхронизация → Подключить устройство» — появится код.
2. На втором: ввести код. Устройства обменяются ключами.
3. Код живёт минуты. Если не успели — создайте новый.

Почта и пароль не нужны. Аккаунт создаётся при подключении к официальному релею и восстанавливается
сид-фразой, которую приложение показывает один раз. Сид-фразу нельзя восстановить — только
пересоздать аккаунт заново.

## Что уходит на сервер

| уходит | не уходит |
| --- | --- |
| шифротекст пакетов изменений | текст заметок |
| идентификатор комнаты | названия папок и теги |
| размер и время | ключ шифрования |
| идентификатор аккаунта, тариф, список устройств | вложения в открытом виде |

Вложения передаются тем же путём: содержимое шифруется вместе с остальным пакетом.

## Свой релей

Релей открыт и ставится отдельно от приложения: Python-сервис с sqlite, в репозитории
[`wssdozh/slag-relay`](https://github.com/wssdozh/slag-relay) есть инструкция по развёртыванию.
После установки укажите его адрес в настройках синхронизации — `http://адрес:порт`. Официальные
адреса подставляются по умолчанию.

Свой релей не требует подписки: тарифы нужны только тем, кто пользуется нашим сервером.

## Если сервер недоступен

Приложение продолжает работать локально, изменения копятся в очереди и уходят при первой
возможности. Ограничение одно: очередь недоставленных вложений занимает место по тарифу.

## Конфликты

Правки разных устройств сливаются по записям: более свежая версия выигрывает, удаления
распространяются как отдельные события и не «оживают» при следующем слиянии.
