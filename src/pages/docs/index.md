# SLAG

Заметки и задачи, которые лежат на вашем диске в открытом markdown. Поток как в мессенджере:
одно поле ввода, Enter — запись создана.

## Из чего состоит

- **приложение** — Windows, Android, Linux. Работает локально, без сети и без аккаунта.
- **хранилище** — папка с `.md` файлами. Папки, корзина и вложения тоже обычные файлы.
- **релей** — необязательный сервер, который передаёт зашифрованные изменения между вашими
  устройствами. Официальный или свой.
- **MCP-сервер** — отдаёт заметки вашим ИИ-клиентам (Claude Desktop, Cursor и другим) через stdio.

## С чего начать

1. [Установить приложение](/docs/install) — Windows, Android или Linux.
2. Выбрать папку хранилища. Если она уже есть с markdown-файлами, SLAG их прочитает.
3. Включить [синхронизацию](/docs/sync), если устройств больше одного.

## Что важно знать сразу

- Ничего не нужно импортировать: приложение работает с тем, что уже лежит в папке.
- Аккаунт не требует почты и пароля. Восстановление — сид-фраза, её показывают один раз.
- Удаление записи — это перемещение в `.trash/`, восстановить можно из корзины.
